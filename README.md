# oasis

My undergraduate research fellowship project where I'm implementing:
- variational quantum linear solver
- quantum approximate optimization algorithm
- quantum-classical physics-informed neural network (for some studied application)

I'm building these algorithms at the smallest scale first and scaling them up to where barren plateaus begin to appear, and studying their dynamical Lie algebras to understand the structure and intuition behind them, and hopefully learning about the classically simulability implications on the road to quantum advantage.
